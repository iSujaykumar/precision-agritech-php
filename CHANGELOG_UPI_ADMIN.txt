No Composer package and no remote QR service.

includes/qr.php
Builds the UPI link and an inline SVG. Error correction is level M. The quiet zone is 4 modules. A bad or missing UPI ID returns no link.

includes/commerce.php
upi_intent() now uses that shared link. Amounts stay whole rupees, matching the order total.

order.php
The pay panel shows the generated QR, payee, amount, UPI ID, copy button and Pay with UPI app. If QR source is "upload", the old image is shown and the amount stays in text beside it.

checkout.php
UPI and bank transfer can be switched off. When UPI is on, checkout names the UPI ID and payee and says the exact QR is created after the order exists.

includes/desk.php
Order emails add the private order link. They do not attach a QR image. CSV cells that start with = + - or @ are prefixed so a spreadsheet will not run them. Desk roles are owner, manager and staff.

admin/payments.php
QR source, method switches, live sample QR (₹1, note TEST), SVG and PNG download, print, and a UPI-app test link.

admin/homepage.php
Hero text, button labels, rail titles, rail on/off and how many trays each rail shows. Defaults match the homepage that was already live.

admin/offers.php
Set or clear an offer on several trays. Badge only, or an old price. Uses the same date rule as the shop.

admin/pages.php
Optional replacement text for the existing policy pages. Empty text keeps the original wording. HTML tags are stripped.

admin/index.php
Adds this week, dispatch, offers, new customers, out of stock and open claims, from the database.

admin/staff.php
New accounts can be owner, manager or staff. Existing accounts stay owner. Staff cannot open payments, settings, coupons, homepage, pages, staff or the database update.

database/schema.sql and database/upgrade.sql
Additive only: users.desk_role and the new settings keys. Upgrade does not change a value that is already saved.

Left as they were
Storefront colours, checkout reservation, COD, bank transfer, reviews, coupons, claims and the manual "I have paid" step.
No payment gateway was added.
