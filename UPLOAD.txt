Upload the contents of this folder into Hostinger public_html.

1. In phpMyAdmin, import database/schema.sql into an empty MySQL database.
   database.sql in the site root is the same file. The web server blocks both.
2. Edit config/config.local.php with the Hostinger database name, user and password.
3. Open https://your-domain/setup once and create the staff login. The page closes after that.
4. Customers sign in with email or the same account's 10-digit mobile, plus password.
   There is no OTP and no password-reset email.

The site is PHP and MySQL only. Do not run Node or npm.
If the database settings are empty, the shop stops. It does not switch to another database.
