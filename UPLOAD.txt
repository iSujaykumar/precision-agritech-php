Upload the contents of this folder into Hostinger public_html.

1. Import database/schema.sql into an empty MySQL database. If the database already exists, open the site once: it adds the new login and stock tables itself.
2. Edit config/config.local.php with the database name, user and password.
3. For mobile codes, add the Twilio Verify keys in that same file:
   twilio_sid, twilio_token, twilio_verify
   Leave them empty and the site will not pretend a code was sent.
4. Password reset uses the server mail function. Test it on Hostinger before relying on it.
5. Open /setup once, only if no staff account exists yet.

Do not overwrite config/config.local.php if it already has the live database password.
